# Licence selection required before public release

This package intentionally has no `LICENSE` file because the authors and their institution have not yet authorised a software or data licence.

Before making the repository public, confirm separately:

1. a software licence for original code;
2. a licence or rights statement for the aggregate source-data files;
3. that no third-party dataset or administrative record is being relicensed;
4. that the chosen terms are compatible with OpenStreetMap/Geofabrik, DATASUS, IBGE, Ipea/IVS, ANS, and other source terms;
5. the version tag and archival DOI strategy.

Do not label the repository MIT, GPL, Apache-2.0, CC0, or CC-BY until this decision is documented. Until then, copyright is retained and reuse permission is not granted by the presence of these files on disk.
