# Code Availability

The analysis and rendering code, frozen scientific contracts, tests, privacy-screened aggregate source data underlying the reported figures and tables, and environment specifications are publicly available at https://github.com/FENG1567/datasus-ercp-reproducibility. Original software in the repository is released under the MIT License. Reused data and external resources remain subject to their original terms.

Record-level SIH/SUS and CNES files, OpenStreetMap and GraphHopper assets, credentials, local paths, and analyses outside the manuscript's descriptive and associational scope are not redistributed. The repository supports integrity checks and regeneration of the publication displays from the included aggregate source data. A complete raw-data-to-result rerun requires reacquisition of the external public data and routing assets listed in the repository documentation. Exact historical dependency locks were not preserved; the supplied environment files specify compatible software versions. No archival DOI has yet been assigned.
