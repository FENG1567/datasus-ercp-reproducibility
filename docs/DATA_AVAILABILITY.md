# Data Availability

This study used routinely collected SIH/SUS and CNES records obtained from DATASUS together with public contextual data from IBGE, Ipea/IVS, ANS, OpenStreetMap, CONITEC, national ordinances, SIGTAP archives, and the documented COVID-pressure series. Record-level SUS/CNES files are not redistributed in this repository. Privacy-screened aggregate source-data files underlying the seven frozen study figures and four frozen result tables are included in `data/source_data/`, with checksums, provenance records, and display mappings.

The reproducibility package is publicly available at https://github.com/FENG1567/datasus-ercp-reproducibility. Before submission, verify that every reused source has a version/release, access date, and stable URL where available. No archival DOI has yet been assigned. The variable-level decomposition of 2,597 Aim 4-excluded records remains `NOT_EVALUATED_NO_FROZEN_ACCEPTED_AUDIT_LOCATED`; no variable-specific counts were inferred.
